# Moxymind – Technical task 1

Automatizované UI testy pre https://www.saucedemo.com/ pomocou Cypress.

## Testovacie scenáre
1. Prihlásenie s platnými údajmi (standard_user)
2. Neplatné prihlásenie (nesprávne heslo → chybová hláška)
3. Pridanie položky do košíka (badge count + položka v košíku)
4. Checkout proces (dokončenie objednávky → success hláška)
